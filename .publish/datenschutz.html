Datenverarbeitung durch die Website

Die Website kann ohne Angabe personenbezogener Daten genutzt werden. Es werden keine Cookies gesetzt und keine Analyseinstrumente oder Trackings eingebunden. Die Seite besteht aus eigenem HTML, CSS und JavaScript; Schriftarten oder Skripte werden nicht von externen Servern geladen. Ein Kontaktformular existiert derzeit nicht. Die Website führt derzeit keine ausgehenden Links zu fremden Websites. Die Sprachauswahl (EN/DE) wird ausschließlich lokal im Browser gespeichert (localStorage) und nicht an die Website übertragen.

Hosting / Server-Logfiles

Die technische Weiterverarbeitung der Website erfolgt über GitHub Pages (GitHub, Inc., USA). Bei jedem Aufruf können Server-Logdaten verarbeitet werden, z. B. IP-Adresse, Zeitpunkt der Anfrage und die abgerufene Seite. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO: ein berechtigtes Interesse an einem fehlerfreien, sicheren Betrieb der Website. Die Logdaten werden gelöscht, wenn sie für diesen Zweck nicht mehr erforderlich sind. Für weiterführende Informationen zur Datenverarbeitung gilt die Datenschutzerklärung von GitHub (https://docs.github.com/en/site-policy).

Risikohinweis

Die Website enthält Projektstatus-Angaben zu einem Token-Projekt. Diese stellen keine Anlageberatung und kein Erwerbsangebot dar. Die genannten Devnet-Testtoken sind reiner Testwert: kein echtes Geld, keine Anlage, kein Verkauf. Der vollständige Risikohinweis ist im Impressum → Risikohinweis dokumentiert.
